# Flappy Bird — Python (Turtle Graphics)

A fully playable Flappy Bird–style game built in Python using object-oriented programming and custom animation logic.

## 🎮 Features
- Gravity-based player movement and jump controls  
- Procedurally generated pipes with randomized gaps  
- Scrolling ground and clouds using wrap-around animation  
- Collision detection and scoring  
- Coin spawning + collection system  
- Skin selection system  
- Start menu and basic leaderboard  

## 🛠 Technologies Used
- Python  
- Turtle Graphics  
- GameABC framework  

## 🚀 How to Run
Clone the repository:
git clone https://github.com/aaminahali72/flappy-bird-python.git

Navigate into the directory:
cd flappy-bird-python

Run the game:
python flappybird.py
